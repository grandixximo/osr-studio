# Contributors and Credits

## Original Project

**Captura** - The foundation of this project
- Created by: **Matthew Sachin** (https://github.com/MathewSachin)
- Original Repository: https://github.com/MathewSachin/Captura

Captura was an excellent screen recording application that set the standard for open-source recording software.

## Continued Development

**nCaptura** - The intermediate fork that kept the project alive
- The nCaptura team for maintaining and improving the codebase
- All contributors who submitted patches, bug reports, and features

## OSR Studio

This fork (OSR Studio) is maintained as a fresh start while honoring the legacy of the original developers. We aim to:
- Modernize the codebase
- Improve user experience with both classic and modern interfaces
- Continue the spirit of open-source screen recording software

## How to Contribute

Contributions are welcome! Please submit pull requests or open issues on our repository.

---

**Important Note**: As stated by Matthew Sachin, this project does not accept monetary donations. The best way to support the project is through code contributions, documentation, testing, and community support.
