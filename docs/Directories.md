# Directory Structure

- **src**
  Contains the source code. It is organized into multiple [projects](Projects.md).

- **licenses**
  Licenses of dependencies.

- **docs**
  Documentation files including build instructions, FAQ, and guides.

- **.github**
  GitHub Actions workflows for CI/CD (automated builds and releases).

- **mathew**
  Original project information and license from Mathew Sachin (Captura creator).

- **temp** (created during build)
  Temporary files generated during the build process.

- **dist** (created during build)
  Build output folder containing compiled executables and dependencies.
