# Contributing to OSR Studio

Thank you for your interest in contributing to OSR Studio! This project continues the legacy of Captura and nCaptura as an open-source screen recording solution.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a feature branch from the appropriate base branch
4. Make your changes
5. Test thoroughly
6. Submit a pull request

## Branch Structure

OSR Studio maintains two main UI branches:

- **classic-ui**: Traditional interface branch
- **modern-ui**: Modern design interface branch

Choose the appropriate branch for your contribution based on which UI you're targeting.

## Code Standards

- Follow the existing code style in the project
- Write clear, descriptive commit messages
- Comment complex logic
- Update documentation for user-facing changes
- Ensure code builds without errors

## Types of Contributions

We welcome:

- **Bug fixes**: Help make OSR Studio more stable
- **Features**: Add new recording/streaming capabilities
- **Documentation**: Improve guides and docs
- **Testing**: Write tests and report bugs
- **UI improvements**: Enhance user experience
- **Performance**: Optimize code and reduce resource usage

## Reporting Issues

When reporting bugs:

1. Check if the issue already exists
2. Use a clear, descriptive title
3. Include steps to reproduce
4. Specify your OS and version
5. Attach screenshots if relevant

## Pull Request Process

1. Update documentation if needed
2. Add yourself to CONTRIBUTORS.md if you'd like
3. Reference any related issues
4. Wait for review and address feedback
5. Maintain patience - reviews take time!

## Code of Conduct

- Be respectful and constructive
- Welcome newcomers
- Focus on what's best for the project
- Show empathy toward other contributors
