# OSR Studio - GitHub Pages

This is the official GitHub Pages site for OSR Studio.

## About

OSR Studio is a powerful screen recording and capture software for Windows. This site provides information about the project, features, and download links.

## Screenshots

The site showcases both Modern and Classic UI versions of OSR Studio:
- **Modern UI** - Featured prominently with theme-aware screenshots (light/dark mode)
- **Classic UI** - Available as an alternative download option with its own showcase

Screenshots automatically adapt to the visitor's system theme preference.
