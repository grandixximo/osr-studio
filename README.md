# OSR Studio

A modern screen recording and streaming application.

## About

OSR Studio is a fork of the nCaptura project, which itself was based on the original Captura application. This project aims to continue the development with improved features and modern UI capabilities.

## Credits

This project is built upon the excellent work of:

- **Matthew Sachin** - Original Captura creator and developer
- **The nCaptura team** - For continuing the Captura legacy
- All contributors to the original Captura and nCaptura projects

## Project Structure

OSR Studio maintains two UI versions:
- **Classic UI** - Traditional interface familiar to long-time users
- **Modern UI** - Updated interface with contemporary design patterns
