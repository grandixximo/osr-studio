# Migration Guide: nCaptura → OSR Studio

## Overview

OSR Studio represents a fresh start for the nCaptura project with a new name and clearer project identity.

## What Changed?

### Branding
- **Old Name**: nCaptura
- **New Name**: OSR Studio (Open Source Recording Studio)

### Project Goals
- Maintain the excellent functionality of nCaptura
- Provide both Classic and Modern UI options
- Continue as a community-driven open-source project
- Focus on code quality and modern development practices

## UI Branches

The project maintains two UI versions to serve different user preferences:

### Classic UI Branch
- Traditional interface
- Familiar to long-time Captura/nCaptura users
- Stable and well-tested

### Modern UI Branch
- Contemporary design patterns
- Enhanced user experience
- New features and improvements

## For Users

When the code is imported:
1. Settings and configurations will be migrated
2. Your recording profiles will be preserved
3. The application functionality remains the same

## For Contributors

When contributing to OSR Studio:
1. Use "osr-studio" in all new code references
2. Update any nCaptura branding you encounter
3. Follow the project's coding standards
4. Consider which UI branch your contribution targets
